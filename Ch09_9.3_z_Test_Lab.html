STOP 1 · THE KEY TERMS

How we decide whether to reject H₀

Recall: H0 is tentatively assumed true; α is the probability of a Type I error that we are willing to accept. Now we need a way to measure the evidence in the sample.

Test statistic

A statistic whose value helps determine whether H0 should be rejected.

For a mean with σ known, it counts how many standard errors x̄ is from μ0:

z =x − μ0σ / √n

Textbook Ch 9 key terms; equation (9.1).

p-value

A probability that measures the evidence against H0. Smaller p-values mean more evidence against H0.

It is the chance of a test statistic at least as extreme as ours if H0 were true. Rule: reject H0 if p-value ≤ α.

Textbook Ch 9 key terms; Section 9.3.

Critical value

A value that is compared with the test statistic to determine whether H0 should be rejected.

It cuts off an area of α in the tail. If z falls beyond it, reject H0.

Textbook Ch 9 key terms.

One-tailed and two-tailed tests

One-tailed test: H0 is rejected for values of the test statistic in one tail of its sampling distribution (Ha uses < or >).

Two-tailed test: H0 is rejected for values in either tail (Ha uses ≠).

Textbook Ch 9 key terms.

The idea in one sentence

Assume H0 is true. If our sample would be very unusual under that assumption (small p-value), we stop believing H0.

Like the jury: if the evidence would be very unlikely for an innocent person, the jury rejects “innocent.”

STOP 2 · THE BOOK'S EXAMPLE · LOWER TAIL

Hilltop Coffee: is the FTC right to suspect underfilling?

The label says a can holds 3 pounds. The FTC treats this as Hilltop's claim that μ ≥ 3 and checks it with a sample of n = 36 cans. Past tests show σ = 0.18 and normal fill weights. The director will risk a 1% chance of falsely accusing Hilltop: α = 0.01.

  1. Hypotheses. H0: μ ≥ 3   Ha: μ < 3 (lower tail)
  2. Level of significance. α = 0.01
  3. Collect the sample and compute the test statistic. σ/√n = 0.18/√36 = 0.03
  4. p-value for a lower tail test = area to the left of z.
  5. Decide. Reject H0 if p-value ≤ α.
Sample mean x 2.920
z = (x̄ − 3) / 0.03−2.67
p-value = P(z ≤ test statistic)0.0038
Compare with α = 0.010.0038 ≤ 0.01
Reject H₀

Start at the book's sample, x̄ = 2.92. Drag x̄ up toward 3: the p-value grows and the evidence weakens.

STOP 3 · TWO APPROACHES, ONE DECISION

p-value approach vs. critical value approach

p-value approach

Find the tail area beyond our z, then compare it with α.

p = 0.0038 ≤ α = 0.01
→ reject H0

Advantage: the p-value tells you how significant the result is. It is also called the observed level of significance: H0 would be rejected for any α ≥ 0.0038.

Critical value approach

Find the z that cuts off α in the tail, then compare our z with it.

−z.01 = −2.33
z = −2.67 ≤ −2.33 → reject H0

Rejection rule for a lower tail test: reject H0 if z ≤ −zα.

Level of significance

The two approaches always agree: whenever the p-value ≤ α, z is beyond the critical value. The shaded α region and the test statistic tell the same story. Uses the x̄ from Stop 2.

STOP 4 · THE BOOK'S EXAMPLE · TWO-TAILED

MaxFlight golf balls: too short or too long is a problem

The process should give a mean driving distance of 295 yards. Too short loses sales; too long breaks the USGA standard. Each quality check uses n = 50 balls, σ = 12, α = 0.05.

H0: μ = 295   Ha: μ ≠ 295

σ/√n = 12/√50 = 1.7. Because either direction counts as evidence, the p-value adds both tails:

p-value = 2 × P(z ≥ |test statistic|)

Critical values: ±z.025 = ±1.96. Reject H0 if z ≤ −1.96 or z ≥ 1.96.

Sample mean x 297.6
z = (x̄ − 295) / 1.71.53
p-value = 2 × one tail0.1260
Compare with α = 0.050.1260 > 0.05
Do not reject H₀

At the book's sample, x̄ = 297.6, the process is left running. Drag x̄ below about 291.7 or above 298.3 to see it rejected.
