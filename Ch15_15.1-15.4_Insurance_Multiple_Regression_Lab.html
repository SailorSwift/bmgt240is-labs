STOP 1 · WHERE CHAPTER 14 LEFT OFF

One x explained 9%. The stripes were telling us something.

Key definitions · Stop 1
Multiple regression analysis
Regression with two or more independent variables x₁, x₂, …, xₚ predicting one dependent variable y.
Independent variables x₁, x₂, …, xₚ
The p variables doing the predicting. Here: x₁ = age, x₂ = BMI, x₃ = smoker.

Chapter 14's line for Bridger Health:

y = 3,165.89 + 257.72·age    r² = 0.089

Age matters (about $258 a year, highly significant), but it explains only 9% of the variation in charges. The scatter had three stripes: smokers on top, and among smokers, BMI separated the top two stripes.

The natural next question: can one equation use age, BMI and smoking at the same time? That's multiple regression.

Why not just run three separate simple regressions?

Because the x's overlap. Older customers have slightly higher BMI. A simple regression on age gives age credit for some of BMI's effect, and vice versa. Multiple regression sorts out each variable's own effect, with the others held constant.

This lab is a concept demonstration: watch the numbers change, and learn to read them. Chapter 15 is not on Exam 2.

STOP 2 · 15.1 · THE MULTIPLE REGRESSION MODEL

Same three equations as Chapter 14, with more x's

Key definitions · Stop 2
Multiple regression model y = β₀ + β₁x₁ + … + βₚxₚ + ε
How y is related to the p independent variables and an error term, one observation at a time.
Multiple regression equation E(y) = β₀ + β₁x₁ + … + βₚxₚ
How the mean of y is related to the x's in the population. The β's are unknown parameters.
Estimated multiple regression equation ŷ = b₀ + b₁x₁ + … + bₚxₚ
The estimate from sample data, found by least squares: the b's make Σ(y − ŷ)² as small as possible.
Coefficient bᵢ
The estimated change in y for a one-unit increase in xᵢ when all the other x's are held constant.
① Model

y = β₀ + β₁x₁ + β₂x₂ + β₃x₃ + ε

Each customer: the population equation plus their own error.

② Regression equation

E(y) = β₀ + β₁x₁ + β₂x₂ + β₃x₃

The average charges for all customers with the same age, BMI and smoking status. Unknown.

③ Estimated equation

y = b₀ + b₁x₁ + b₂x₂ + b₃x₃

What Excel computes from the data. Least squares works exactly as in Chapter 14.

In Excel: the same Regression tool, a wider X range
  1. Put all the x columns next to each other (the tool needs one contiguous block).
  2. Data › Data Analysis › Regression. Input Y Range = charges. Input X Range = all the x columns at once. Check Labels.
  3. The output looks the same as in Chapter 14, with one row per x in the coefficients table.

Reading it: the one sentence that matters

Holding BMI constant, each extra year of age adds about $242 in annual charges. Holding age constant, each extra BMI point adds about $333.

  • Why did age drop from $258 to $242? Older customers have slightly higher BMI (r = 0.11). On its own, age was getting credit for a little of BMI's effect. Now BMI gets its own credit.
  • “Holding constant” in plain words: compare two customers with the same BMI who differ by one year of age. The model says the older one costs about $242 more.
  • The intercept (−$6,425) is ŷ at age 0 and BMI 0. Neither is in the data, so it has no practical meaning.
  • Fit: R² = 0.117. Better than 0.089, but BMI alone doesn't explain the stripes.
STOP 4 · A THIRD PREDICTOR: SMOKER

Turn yes/no into 1/0, and the stripes explain themselves

Workbook: fill column E on the Data sheet, then Input X = columns C:E. Answers on Run 3 + smoker.

Key definitions · Stop 4
Dummy (indicator) variable 0 or 1
A yes/no category coded as numbers so regression can use it: smoker = 1 for yes, 0 for no. (Section 15.7; shown here as a preview.)
Coefficient of a dummy variable
The difference in predicted y between the “1” group and the “0” group, holding the other x's constant.
Make the column

In E2 on the Data sheet: =IF(B2="yes",1,0), then double-click the fill handle. Smokers get 1, non-smokers 0.

Holding age and BMI constant, a smoker costs Bridger about $23,824 more per year than a non-smoker. Three variables together explain about 75% of the variation in charges, and the typical pricing miss is nearly cut in half.

smokernon-smokerlines: the model at average BMI (30.7)

The two lines are parallel: same slope for age ($260 a year), shifted up $23,824 for smokers. That is exactly what “holding the other variables constant” looks like. The middle stripe is mostly smokers with lower BMI; the BMI term moves each customer up or down from these lines.

STOP 5 · 15.3 · MULTIPLE COEFFICIENT OF DETERMINATION

R² always goes up. Adjusted R² has to earn it.

Key definitions · Stop 5
Multiple coefficient of determination R² = SSR / SST
The proportion of the variation in y explained by the estimated multiple regression equation. Same idea as r² in Chapter 14.
Adjusted multiple coefficient of determination R²ₐ
R² adjusted for the number of independent variables, R²ₐ = 1 − (1 − R²)(n − 1)/(n − p − 1). It can go down when a useless variable is added.

The experiment: add a variable that cannot matter: each customer's row number in the file.

Predict first

Adding row number to age + BMI, what happens to R²?

ModelR²Adjusted R²
age + BMI0.117180.11586
age + BMI + row number0.11732 ↑0.11533 ↓

R² went up, even for a meaningless variable: least squares can always use an extra x to shave a little off SSE. Adjusted R² went down, because the tiny gain wasn't worth an extra variable. (Row number's p-value is 0.65.)

The rule for comparing models

Adding an x never lowers R². So when models have different numbers of x's, compare them with adjusted R², which only rises if the new variable helps enough.

ModelpR²Adjusted R²s
age10.0890.089$11,560
age + BMI20.1170.116$11,387
age + BMI + smoker30.7480.747$6,092

With 1,338 customers, R² and adjusted R² barely differ; the penalty matters most when n is small and p is large. 15.4: the assumptions about ε are the same four as in 14.4, now for the multiple model.
