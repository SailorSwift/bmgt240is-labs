STOP 3 · 8.3

We need σ before we sample. Where does it come from?

About 95% of a roughly normal variable lies within ±2σ of the mean, a span of 4σ. So range ≈ 4σ, and σ ≈ (60,000 − 45,000)/4 = $3,750 (Q6a).

Ways to get a planning value for σ

  1. Use the standard deviation from a previous study of the same or similar units.
  2. Run a small pilot study and use its sample standard deviation.
  3. Use judgment or a best guess, for example range / 4 when only a typical range is known.

Planning values are approximate. That is one more reason to round n up.

Q6(c) · Would you recommend E = $100?

Probably not. It needs 5,403 graduates, 25 times the 217 needed for E = $500. A $500 margin on a salary near $52,500 is already under 1%, so the extra cost is hard to justify.
